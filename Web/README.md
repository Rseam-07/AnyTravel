# AnyTravel Web

AnyTravel 的浏览器端，使用 React、TypeScript、Vite 与 MapLibre GL。当前界面以 iOS 端为产品和视觉基准：地图始终是主画布，顶部使用同层级的旅程状态栏，桌面为左侧悬浮面板，移动端为可拖拽三档浮动面板；生成后只展示当前一天的路线和序号地点，并使用与 iOS 一致的“行程 / 住宿 / 交通 / 费用”结构。

## 本地启动

```sh
cd Web
npm install
npm run dev
```

默认地址是 `http://127.0.0.1:5182/`。开发服务器会把 `/health` 和 `/v1` 代理到本机伴随服务；生产版本由 Backend 同源提供网页和接口。地图与本地规划可以离线降级，铁路、门票、酒店目录、渠道状态和托管智能向导则使用 `Config/ServiceDefaults.json` 中的公共服务。正式 1.0 不要求用户填写地址，部署方法见 [公共服务部署](../Documentation/PRODUCTION_SERVICE.md)。

## GitHub Pages

仓库包含 `.github/workflows/deploy-web-pages.yml`。将 `main` 推送到 GitHub 后，Actions 会在 Ubuntu runner 上安装锁定依赖、构建 `Web/dist`，再发布到 GitHub Pages。首次启用时，在仓库的 **Settings → Pages → Build and deployment** 将来源设为 **GitHub Actions**；之后每次修改 Web 或默认服务配置都会自动部署。

Pages 使用相对资源路径，因此仓库站点地址形如 `https://<账号>.github.io/AnyTravel/`。当前 `Config/ServiceDefaults.json` 没有公共后端地址，Pages 仍可使用内置目的地资料、地图和离线规划；酒店、交通、门票和托管向导只有在配置可从浏览器访问的 HTTPS 服务后才会显示实时结果。需要接入公共后端时，在仓库 **Settings → Secrets and variables → Actions → Variables** 增加 `ANYTRAVEL_SERVICE_URL`（只放 HTTPS 根地址，不放 token）；工作流会在构建时注入它，后端还需允许 Pages 域名的 CORS。

供应商和模型密钥应放在 `Backend/.env`，不要写入 `Web/.env.local`。设置页仍保留一个明确标为“不推荐”的浏览器直连 DeepSeek 备用入口，只适合用户自带、可随时轮换的密钥。

## 当前可用流程

- 从地图选目的地，不先填写长表格；可补充出发地、日期、天数、人数、预算、节奏、兴趣和市内移动方式。
- 三端共用的离线目的地资料覆盖 162 个目的地，其中 141 个在中国，共 1,234 个候选地点和 867 个去重来源；实时地点可从伴随服务补充，失败时仍能用本地资料生成方案。
- 规划器按空间、停留时长、午餐、夜间活动和每天容量分组。松弛档最多安排两处主要游览，再按需要补一处用餐和一处夜间停留；排不下的地点会明确留在候选中。
- 当前一天的路线使用白色描边与独立日色，地图和面板切天同步；点击时间轴地点会聚焦地图。
- 住宿有真实酒店时显示来源、价格和购买入口；未配置酒店渠道时改为推荐“落脚片区”，不会生成虚构酒店或价格。
- 填写出发地后可查询 12306 去返程班次、余票、席别起价和官方购买页；无精确站点坐标时地图只显示“抵达范围（示意）”。
- 门票只查询主要游览点，并过滤街区、书店、商场、公园、开放湖区、博物馆、普通地标、餐饮和夜间活动的付费套餐错配；未高置信命中时显示待查。
- 费用页区分渠道实时价、本地估算和预算预留；选择住宿或班次后自动更新。
- 支持一句话修改天数、人数、预算、节奏、兴趣和移动方式，并真正重新生成路线；托管模型不可用时仍有本机中文规则回退。
- 支持旅册保存完整路线、地点顺序、住行选择与报价快照；自动保留上次旅程，可读备份损坏时回退，删除进入可恢复的“最近删除”。历史报价恢复后明确标为待刷新。另有分享条件、打印/PDF、明暗地图、定位和北向恢复。
- 支持安装为 PWA；首次完整打开后，应用外壳和内置目的地资料可离线重开，地图瓦片、天气、营业和价格仍需网络更新。

## 数据边界

- 地图路线优先请求 OSRM；网络不可用时使用地点之间的直连距离和时间估算，并在说明中标明。
- 12306、去哪儿与酒店渠道展示的是查询当刻的公开信息，不是锁价或订单确认；提交前必须到来源页面复核。
- 酒店实时价取决于 RollingGo、携程、同程、艺龙或万邦等服务端配置。没有凭据时，渠道状态会明确显示 `disabled`，但行程和落脚片区仍可用。
- 浏览器不保存平台账号密码。需要登录会话的采集由本机伴随服务的持久化浏览器配置承担。

## 验证

```sh
npm run assemble:knowledge
npm run check:knowledge
npm test
npm run build
```

浏览器验收至少覆盖：选择目的地、生成、切换日期、聚焦地点、住宿空态、补充出发地、铁路去返程、费用、一句话调整、旅册与移动面板三档。
