# AnyTravel Web

浏览器版 AnyTravel：React + TypeScript + Vite + MapLibre GL，桌面为大屏横排（左侧面板 + 全屏地图 + 底部行程轨道），移动端为可拖拽三档底部面板。UI 语义与 iOS 一致（同色板、同行程模型、同渠道状态语言），视觉参考 Apple Maps 的地图优先布局。

## 启动

```sh
cd Web
npm install
cp .env.example .env.local         # 可选：VITE_DEEPSEEK_API_KEY（对话用，不进 Git）
npm run dev                        # http://127.0.0.1:5182
```

需要同机（或局域网）启动伴随节点提供报价与地点：见 `Backend/README.md`。节点地址与 DeepSeek Key 也可以在 App 内“设置”中填写，只存本机浏览器。

## 当前已可用的闭环（本机实测）

- 界面材质与 iOS 一致：半透明毛玻璃面板（浅/深两套，地图透出），官方“折叠远方”Logo 与 favicon。
- 默认接通：默认出发日期；方案生成后自动预选最低价住宿与去返程班次并提示“已帮你预选”，可在对应页更换。
- 目的地搜索（OSM Nominatim 地理编码，经节点代理）、出发地、日期、天数、人数、预算、节奏、兴趣与市内移动；景点源按 Overpass → 内置地点包（苏州/杭州/青岛/上海/北京，坐标人工核对）→ Nominatim 三级兜底，任何网络状况都能出方案。
- 生成方案：OpenStreetMap POI（Overpass 经节点，含真实营业时间）作为景点源，空间聚类 + 近邻排序 + 时间表（停留/移动/午餐/夜游/机动），超载时明确提示；OSRM 可用时用真实路网耗时替代直线估算。
- 一周天气预报（Open-Meteo），直连浏览器接口。
- 住宿目录与实时价：与 iOS 同一批渠道（RollingGo 实测返回真实价格；携程/同程/艺龙/万邦按配置状态显示），筛选与“N家比价”标签。
- 铁路去返程：12306 公开展示价与余票（节点已有适配器，实测返回真实车次票价）；去哪儿门票公开起价回填（实测拙政园 ¥80 等）。
- 智能对话：内置 DeepSeek（浏览器直连，Key 来自构建配置或设置页），白名单动作（目的地/日期/人数/预算/节奏/兴趣/交通）落回地图，回复展示自然语言；节点不可达时提示在设置里补 Key。
- 费用表：大交通、住宿、门票（实时/估算分级）、市内交通与餐饮估算、预算对比。
- 旅册（本机保存）、分享链接（URL 参数还原条件）、打印/PDF（打印样式表）、地图样式切换、定位、北向、深浅色。

## 诚实边界

- 浏览器不持有平台密钥：所有报价与地点经伴随节点；DeepSeek Key 是用户自己的，只存浏览器/构建配置。
- 景点路线在取得 OSRM 真实几何前画为直连示意；公交没有路网级几何（Node 端渠道有则替换）。
- 高德当前 Key 平台类型不匹配（`USERKEY_PLAT_NOMATCH`），地点搜索以 OSM/Overpass 为主；换取正确的“Web 服务”Key 后无需改代码。
- 无节点时：方案仍可生成（OSM 直连兜底 + 本地估算），但住宿/交通/门票实时价与渠道健康都明确标为未连接。
- Web 版尚无：平台网页登录会话（去哪儿/携程/同程 Cookie 复用）、行程编辑拖动、多城市、版本历史——列入 `Documentation/PLAN_TO_1_0.md` 的 M4–M6。
