# AnyTravel 功能路线图

> 旅行不是把地点塞进表格，而是让时间、预算、住处与抵达方式在地图上彼此照亮。

这份清单以“用户能否完成一次真实任务”为验收标准。只有入口、静态卡片或演示数据不会标为完成；联网数据必须显示来源、抓取时间和失败状态。参考应用的条目来自静态资源与模块结构，只用于功能盘点，后续仍需逐条走查验证。

| 旅程环节 | 当前能力 | 验收边界 |
| --- | --- | --- |
| 初次进入 | 四页欢迎与初始化设置；保存出发地、人数、预算；默认松弛节奏 | 可重新进入设置，减少动态效果时自动简化动画 |
| 地图规划 | 地图为全屏背景，地点、住宿、车站和每日路线随卡片选择联动；iOS 与 Android 面板可在仅输入框、中档和几乎全屏之间连续拖动，并按当前流程自动回到合适高度 | 用户拖动地图后停止自动抢镜；点卡片可重新聚焦；最大档自动收起会压住内容的地图控件 |
| 自由输入 | 首页开放自然语言输入；目的地、出发地、日期/天数、人数、预算、兴趣、节奏、住宿筛选和交通可在一句话中任意组合，也可跳过；生成前可先浏览“先挑想去的地方”，勾选主游览点或交由 App 按热度与空间分布代选 | 模型动作经白名单后直接更新地图；服务失败时由本机解析器执行可确定部分，原文仍可修改重试；景点候选跨 MapKit 与高德合并，只接受 60 公里内且名称可信的去处 |
| 景点与路线 | 三端共用 141 个国内目的地资料；真实地点搜索、跨来源地点归一（公开热度、评分、官方 5A 校验与距离排序）、逐日分组、距离与预计时间；iOS 使用 MapKit 逐路段路径，Android 优先使用 Valhalla 道路几何 | 同名同址或名称包含关系且坐标相近的自动结果会合并；相距较远的同名分店保留；勾选的主游览点按 1.28 倍停留时长编排；在线路由失败才降级为明确标记的示意线 |
| 方案编辑 | iOS 可搜索加点、拖动排序、跨天移动/复制、删除和撤销重做；Android 可地图长按加点、同日/跨天移动、删除和撤销重做；两端均可修改旅行条件 | 每天至少保留一处；路线变化后重新绘路并使住宿、接驳与报价进入待复核状态；Android 搜索加点、拖拽和复制仍待补齐 |
| 住宿 | 多关键词 MapKit/系统目录与 RollingGo 城市/景点锚点目录合并；显示景点均距、枢纽距离、品牌、设施、实时价和官网，并支持排序筛选；同一家酒店可展示多渠道报价与“N家比价” | RollingGo 优先；雅高官网提供公开选日房价，希尔顿官网补目录和直营入口；已登录携程会话可返回实时报价；艺龙与万邦未配置凭据时显示 disabled |
| 景点门票 | iOS 按行程地点读取去哪儿公开展示起价，并写入地图卡、时间轴和多人费用 | 保留抓取时间与购买入口；公开起价不冒充指定日期、票种或库存 |
| 大交通 | 铁路去程/返程独立班次、席别、余票、价格、选择与购买入口；航班默认读取飞猪公开 H5 数字报价，保存去哪儿会话后叠加去哪儿结果，节点侧另有携程会话通道；同一航班跨渠道合并 | 单边查询失败不会遮住另一边；实时价、参考价和待查询状态分开展示；每个渠道的起价、抓取时间和购买入口各自保留，需要复核税费与舱位 |
| 门到门接驳 | iOS 分别比较去程枢纽→住宿、住宿→返程枢纽的公交、打车与步行，并联动地图和费用 | 真实 MapKit 路线与距离估算分开标注；估算公交不会冒充已取得路线 |
| 完整方案 | 空间聚类、逐段移动、营业时段、类型停留时长、用餐、休息、夜游、抵达/返程边界、住宿、交通和费用明细 | 默认松弛；估算与真实路线/班次分开标注，超载不会静默删景点 |
| 方案导出 | iOS 与 Android 原生生成多页 PDF 与可导入日历的 `.ics`，并通过系统分享页交付 | 没有日期仍可导出 PDF；日历必须先补日期；地图失败时保留文字方案并明确说明 |
| 行程保存 | 本地保存、查看、恢复与删除；两端恢复后自动复核路线、住宿与报价 | Android 存储时剥离可重新计算的路线几何，避免大型行程压垮偏好存储；旧价格不会被无提示地当作新报价 |
| 平台会话 | iOS 支持携程、去哪儿、飞猪、同程、Trip.com、12306 的应用内网页登录；Android 提供平台入口 | iOS 以有效平台 Cookie 校验会话状态；密码只交给平台网页；Android 会话复用仍待实现 |
| 智能向导 | iOS 支持伴随服务托管 GLM 与用户自定义 OpenAI 兼容模型；可控制旅行条件、兴趣、住宿筛选、地图焦点并直接生成 | 服务端 Key 不进入 App；自定义 Key 只进钥匙串；所有地图动作均经本地白名单复核 |

## 不会用“完成”掩盖的边界

- 静态资源中的功能名称不能证明参考应用的全部行为，深入走查会后续补做。
- 聚合页展示的数字只有在酒店、日期、房型与价格口径匹配后才会标为实时价。
- 平台登录状态不等于已经获得可用接口；失败时仍保留其他渠道和官方购买页。
- 模拟器通过不等于真机、弱网和长期会话通过；每个版本都会单独写明验证范围。
