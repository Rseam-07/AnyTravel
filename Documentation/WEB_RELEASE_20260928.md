## 仍需保留的边界

- 自动航班源仍受限；已提供正常网页查询和人工核对后导入，不能宣称全自动实时机票服务可用。
- 规划时间不等于预约成功；未确认的营业时间、节假日例外、库存与优惠资格须在原平台核实。
- 目前市内公交耗时为估算；每日起点仍为城市中心，未自动采用实际住处。用户设置首末日窗口并预留接驳。
- 未进行 Safari、真实 iOS/Android 设备或弱网性能验收。本次发布范围是网页与配套后端。

发布由仓库现有 GitHub Pages 工作流执行。回滚网页可还原这次 Web 提交后重新运行该工作流；后端用 Cloudflare 的上一版本恢复。当地浏览器行程与手册仍存本机，升级不执行数据清空。
