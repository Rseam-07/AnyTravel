# AnyTravel 1.0：一次旅行的可用性清单

更新：2026-09-05。基线：v0.8.2 / efcec07。此表从用户任务出发；替代旧计划中“可自行配置即算可用”和“无签名 IPA 即算大众发布”的验收口径。已有能力不从零重做，未经过实际流程验证的项目不会勾为完成。

## 1.0 的含义

普通用户打开网页或安装应用，不注册开发者账号、不配置 API、不搭服务器，即可规划、编辑、保存并查看真实住行报价。三端拥有同一组核心能力与一致的业务状态。自定义模型、自建服务仍可保留，但只是高级选项。

“同步”首先指三端同版本功能与数据契约一致；跨设备同步个人行程是另一个明确的功能，不能用同步代码冒充云同步。

## 1.0 之后再考虑，不挤占可靠性工作

足迹统计、旅途日记与海报、社交推荐、价格历史可视化、复杂多人实时协作。收藏与基础只读分享优先；平台内支付/自动订票不作为默认能力，避免让用户误以为规划器已完成交易。
