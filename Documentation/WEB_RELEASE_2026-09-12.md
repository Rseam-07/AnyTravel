# AnyTravel Web 0.8.4 发布记录

网页：https://rseam-07.github.io/AnyTravel/

后端：https://anytravel-api.ny-ravel.workers.dev

前端由 GitHub Pages 发布，后端使用 Cloudflare Workers Free。用户打开网页即可规划、查价与使用向导，无需填写 API Key。Cloudflare 发布保留的版本为 244e2a49-019b-45b4-8869-66af4802ba0f。

## 这次交付

- 步行与驾车分别使用真实道路图，按可见日期请求和缓存；地图显示日色、序号、方向箭头、道路/示意状态和一键全程视野。缺失坐标不跨点连线，返回同一地点的行程保留回程段。
- 参考 Travel-Plan-Page 整合随行手册：航班/车次倒计时、每日行程、可筛选路线图、票券 PDF/图片、租车自驾资料、行前清单、同行分账、CSV、完整 JSON 备份、打印和两种参考项目资料格式导入。保留 MIT 许可和来源说明。
- 手册以 IndexedDB 本地保存。用户可创建带私密分享码的云端副本；跨设备上传、拉取遇到版本冲突会提示，避免覆盖同行人的修改。
- Workers AI Qwen 接管自然语言理解；原 DeepSeek 账号没有可用余额时不再阻塞。云端额度不可用仍回退到有标注的本地规则。
- 修复中文城市名被活动词吞入、上海误触发海边偏好、目录中远郊低价酒店被自动选中、地图样式切换报错、账本连续录入保存刷新等问题。
- Vite 只暴露显式公共变量；本机环境文件、Cloudflare 状态和生成资产均不提交。PWA 预缓存地图及手册延迟加载代码，便于断网重开。

## 已验证

- Web：12 个测试文件、46 个测试通过，生产构建通过。
- Backend：70 个测试通过，覆盖来源解析、金额口径、意图动作校验与手册持久保存。
- 内置资料：162 个目的地、1,234 个地点、867 个来源，知识库校验通过。
- Cloudflare 真正线上请求：苏州住宿 19 条带价结果；上海到苏州铁路 8 条带价结果；拙政园公开门票起价；Qwen 正确解析城市、天数、人数和节奏。
- 手册服务：来源限制、预检、无分享码拒绝、跨分块完整恢复、并发更新 200/409 冲突检查通过。
- 浏览器：清单刷新保留；两名模拟同行人的 101 元账单保存并得出 50.50 元结算；参考项目 JSON 导入为独立手册。
- 凭据检查：当前源码、生成网页与 967 个历史 Git blob 中均未匹配到本机 3 个实际供应商/模型密钥。这里记录的是已提供凭据的精确匹配检查，不能代替所有未知凭据的通用审计。

## 当前边界

- 飞猪旧接口已停用，已适配官方 listingsearch 2.2 的分币金额、成人含税价和跨日中转。公开接口验证曾成功返回 62 个报价，但正式服务目前遇到访问限制，因此页面明确显示查询失败/验证限制，并提供官方查询入口；不能声称自动机票报价已经稳定接通。严格 --live 烟测在此项仍会失败。
- Cloudflare 版本不启用需要持久浏览器登录的携程、同程通道；雅高和希尔顿在本次线上请求失败，RollingGo 住宿结果继续可用。
- 当前高德凭据类型不兼容 Web 服务时，地点使用有来源标注的 OpenStreetMap 回退。
- 地图瓦片、道路计算、天气和实时价格需要网络；PWA 离线可用不表示拥有全部离线地图。
- 分享码持有者能读写整本手册；同步由用户触发。断开本机连接不会撤销云端分享码。当前云端最多 100 本共享副本，每本 32 MB。
- 价格是来源查询时的展示价，购买、税费、票种、优惠、行李和退改须在官方购买页面复核；本应用不代替下单支付。

本记录只覆盖 Web 和公共后端；未把本轮称为 iOS/Android 正式签名版本或三端 1.0 完整验收。
