# 方案导出

AnyTravel iOS 0.5.4 可以从完整方案页直接导出 PDF、日历文件，或把两者一起交给系统分享页。

## PDF

- 使用 iOS 原生 PDF 渲染生成 A4 多页文件，不依赖远端排版服务。
- 首页包含旅行条件与地图总览；后续依次写入每日时间表、地址、住宿、往返大交通、门到门接驳和费用明细。
- 地图只绘制 Apple Maps 已经返回的路线。地图快照或路线暂时不可用时，文件保留完整文字方案并明确说明，不补画虚构道路。
- 行程没有日期时仍可生成 PDF，日期位置会按未填写状态呈现。

## iCalendar

- 每个日程条目写成独立 `VEVENT`，包含开始/结束时间、地点与说明。
- 文件采用 `.ics` 标准格式并按 75 字节折行，可由系统日历和兼容日历应用导入。
- 日程按导出设备当前时区解释。没有出发日期时不会制造日期，应用会提示先补充日期。

## 文件交付与隐私

导出文件先写入应用的临时目录，再交给 iOS 系统分享页。用户可以保存到“文件”、隔空投送、打印或交给其他已安装应用。文件只包含当前方案里已经显示的信息；平台登录 Cookie、报价节点密钥和密码不会进入导出内容。
